# Map provenance

The two files under `source/` are original competition-map exports for 2010 and 2022. The public Python helper only crops and places them side by side to create `coupling_coordination_2010_2022.png`.

This raster plate is retained as provenance rather than used as the README hero. Because the complete GIS layers are unavailable, the public workflow cannot regenerate a clean common map, and the original four-class purple palette makes temporal differences difficult to compare.

The underlying administrative boundary layer, GIS project, classifications and spatial inputs are not included. The comparison plate is therefore a communication asset rather than a reproducibly generated geospatial result. No boundaries or values have been traced or fabricated.
